## ดูรายชื่อโมเดลใน LLM gateway

**Trigger:** เมื่อถูกถามว่า "มีโมเดลอะไรบ้าง" "โมเดลกี่ตัว" "ตัวไหนทำ OCR ได้"
"มีโมเดลภาษาไทยไหม" "ตัวไหนถอดเสียงได้" หรืออะไรก็ตามที่ต้องรู้ว่า gateway มีอะไร

### 🔴 ห้ามขอ API key จากผู้ใช้เด็ดขาด

key อยู่ในตัวแปร `$LITELLM_KEY` ของเครื่องนี้อยู่แล้ว ใช้ได้ทันที

ถ้ายิงแล้วได้ 401 **อย่าถามผู้ใช้ว่าจะให้ส่ง key มาไหม** — ให้ตรวจว่าใส่ header
ถูกหรือยัง แล้วบอกผู้ใช้ว่าติดตรงไหน การชวนให้คนพิมพ์ API key ลงในแชทเป็นสิ่งที่
ห้ามทำ เพราะแชทกลุ่มมีคนอื่นเห็นและถูกเก็บไว้ถาวร

### คำสั่งหลัก

```bash
curl -sS --max-time 30 http://llm-litellm:4000/model/info \
  -H "Authorization: Bearer $LITELLM_KEY" \
  | python3 -c "
import json,sys
d = json.load(sys.stdin)['data']
print(f'ทั้งหมด {len(d)} ตัว')
for r in d:
    mi = r.get('model_info') or {}
    print(r['model_name'], '|', mi.get('status'), '|', mi.get('tags'))
"
```

ปรับเงื่อนไขใน loop ตามที่ถูกถาม เช่น

- **หมวด** — `if 'ocr' in (mi.get('tags') or []):`
  หมวดที่มี: `coding-best` `coding-ok` `thai` `web-access` `fast` `no-api-key`
  `quality-top` `long-context` `embedding` `ocr` `asr` `deprecated`
- **ขึ้นต้นด้วย** — `if r['model_name'].startswith('th/'):`
- **เรียก tool ได้** — `if mi.get('supports_function_calling') is True:`
- **ยังใช้ได้** — `if mi.get('status') == 'ok':`

### ข้อควรรู้ตอนตอบ

- **`jq` ไม่มีในเครื่องนี้** ใช้ `python3` เท่านั้น
- ผลลัพธ์ ~580 KB **อย่าพิมพ์ทั้งก้อน** ให้กรองก่อนเสมอ
- `/model/info` **ไม่ใช่ LLM call เรียกกี่ครั้งก็ไม่เสียโควตา`
- `status` เป็นภาพตอน health-check ล่าสุด **ไม่ใช่สภาพตอนนี้** — ถ้าจะบอกว่า
  "ตัวนี้ใช้ได้" ให้บอกด้วยว่าอ้างจาก `status_checked_at` เมื่อไหร่
- ถ้าฟิลด์ที่ถูกถามไม่มีในข้อมูล **ให้บอกตรง ๆ ว่าไม่มี** แล้วเสนอวิธีอื่น
  อย่าเดาแทน เช่น อย่าสรุปว่าเป็นโมเดลไทยเพราะชื่อขึ้นต้นด้วย `th/`
  ถ้า `tags` ไม่ได้บอกไว้ — ให้บอกว่ากรองด้วยชื่อนะ

### ผู้ใช้อยากลองสลับไปโมเดลที่เห็น

พิมพ์ `/model <ชื่อ>` ได้เลย ใช้ได้กับทุกตัวใน gateway ไม่ใช่แค่ตัวที่อยู่ใน config

⚠️ บางตัวสลับไปแล้วใช้ไม่ได้จริง เช่น `th/typhoon2.5` ที่ provider จำกัด
`max_tokens` ไว้ที่ 16,384 — ถ้าสลับแล้วเจอ error ให้บอกผู้ใช้ว่ากลับด้วย
`/model mi/ministral-14b` ซึ่งเป็นตัวหลักที่ผ่านการทดสอบแล้ว

### จุดที่ตั้งใจใส่

กฎห้ามขอ key อยู่บนสุด — ไม่ใช่หมายเหตุท้ายไฟล์ เพราะเป็นเรื่องที่พลาดแล้วเสียหายจริง

บอกว่า jq ไม่มี — สาเหตุที่บอทตอบไม่เหมือนกันทุกครั้ง เพราะต้องเขียนตัว parse เองแล้วบางครั้งพลาดเงียบ ๆ

สอนให้บอกว่ากรองด้วยอะไร — ตอนทดสอบมันสรุปเองว่า th/* = ภาษาไทย ซึ่งบังเอิญถูก แต่วิธีคิดผิด

ทางออกตอนสลับแล้วพัง — เคส th/typhoon2.5 ที่เราเพิ่งเจอ ให้ผู้ใช้ไม่ติดค้าง
